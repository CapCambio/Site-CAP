CLASSES CRÍTICAS PARA ALINHAMENTO
Container principal: flex flex-col sm:flex-row sm:items-center sm:justify-between
Ambos os campos: relative flex-1
Segundo campo: mt-3 sm:mt-0 (margin-top apenas no mobile)
Botão central: sm:mx-4 sm:flex-shrink-0
Altura dos campos: h-14 sm:h-[4.5rem] (IDÊNTICA em ambos)
DIFERENÇAS ENTRE OS CAMPOS
PRIMEIRO CAMPO:

Margin bottom: mb-3 sm:mb-0
Margin top: NENHUM
SEGUNDO CAMPO:

Margin bottom: NENHUM
Margin top: mt-3 sm:mt-0
RESPONSIVIDADE CRÍTICA
Mobile (flex-col):

Campos empilhados verticalmente
Primeiro campo: sem margin-top, com mb-3
Segundo campo: com mt-3, sem margin-bottom
Desktop (sm:flex-row):

Campos lado a lado: sm:items-center
Ambos os margins zerados: sm:mb-0 e sm:mt-0
Alinhamento central: sm:items-center

    <div className="bg-white rounded-xl flex justify-between items-center p-3 mb-3 sm:mb-0 h-14 sm:h-[4.5rem]">
      {/* Conteúdo do input */}
    </div>
  </div>
  {/* BOTÃO DE TROCA */}

</div>
PONTOS CRÍTICOS
ALTURA IDÊNTICA: Ambos os campos DEVEM ter h-14 sm:h-[4.5rem]
MARGIN ESPECÍFICO: Primeiro campo mb-3 sm:mb-0, segundo campo mt-3 sm:mt-0
FLEX-1: Ambos os containers devem ter flex-1 para ocupar espaço igual
ITEMS-CENTER: O container principal DEVE ter sm:items-center para alinhar no desktop
IMPORTANTE: Use exatamente essas classes. O desalinhamento acontece quando as alturas ou margins não são idênticas.
