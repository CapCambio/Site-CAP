PROBLEMA CRÍTICO: Line Chart desaparece ao navegar para dias anteriores no calendário

Contexto:

Aplicação React com line chart usando Recharts
Componente CurrencyMiniChart.tsx que mostra gráfico histórico de moedas
O componente tem calendário para navegação entre meses
PROBLEMA: Quando o usuário navega para um dia anterior do mesmo mês no calendário, a linha do gráfico desaparece completamente
Comportamento Esperado:

O line chart deve sempre mostrar dados do mês inteiro, independente do dia específico selecionado no calendário
Se estou em 23/06 e volto para 17/06 (mesmo mês), o gráfico deve continuar mostrando dados de todo o mês de junho
Comportamento Atual:

Ao selecionar um dia anterior no calendário, a linha do gráfico some
O gráfico funciona corretamente apenas quando mostra o mês atual até hoje
